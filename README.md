# Courant

Courant is a from-scratch AI-powered spoken-English learning platform inspired by the product experience and feature set of Fluento, with original Courant branding, content, and implementation.

## Product scope

- Marketing site and product onboarding
- AI tutor conversations
- Multilingual practice
- Grammar, pronunciation, vocabulary, pitch, pace and volume coaching
- Confidence and presentation feedback
- Scenario-based interactive labs
- Curriculum, units and lesson progression
- Student progress and before/after recordings
- Creator Studio / portfolio workflows
- Teacher and school dashboards

## Stack

Next.js + TypeScript + Tailwind CSS + shadcn-style components. Backend and AI providers will be integrated behind typed service boundaries so they can be swapped without rewriting the UI.
